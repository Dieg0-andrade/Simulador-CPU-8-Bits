# Simulador de CPU de 8 bits

Simulador interactivo de una CPU de 8 bits basado en la arquitectura de Von Neumann.

## Plataforma
El proyecto será desarrollado usando:

- Google Sheets
- Google Apps Script
- JavaScript

## Objetivo
Simular el funcionamiento básico de una CPU de 8 bits, incluyendo memoria principal, registros, ALU, unidad de control y el ciclo de instrucción Fetch–Decode–Execute–Store.
